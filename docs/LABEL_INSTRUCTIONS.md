# 标签指令定义规范

## 概述

本文档定义了商品标签渲染系统所支持的各种指令及其参数规范。每条指令都遵循统一的格式，以便于解析和渲染。

## 指令格式

所有指令采用以下统一格式：
```
instruction,value1,value2,value3,...
```
其中指令名和各个参数值之间使用逗号(,)分割，参数值按照固定顺序排列，不需要指定参数名称。

## 指令定义

### 1. 文本指令 (text)

#### 指令语法
```
text,<X坐标>,<Y坐标>,<宽度>,<高度>,<字体大小>,<字体族>,<字体粗细>,<对齐方式>,<颜色>,<文本内容>
```

#### 指令描述
用于在标签上显示文本内容

#### 指令参数
| 参数名 | 类型 | 必填 | 有效值 | 描述 |
|--------|------|------|--------|------|
| x | number | 是 | 数值 ≥ 0 | 文本左上角X坐标 |
| y | number | 是 | 数值 ≥ 0 | 文本左上角Y坐标 |
| width | number | 是 | 数值 > 0 | 文本区域宽度 |
| height | number | 是 | 数值 > 0 | 文本区域高度 |
| font-size | number | 是 | 1-100 | 字体大小(pt) |
| font-family | string | 是 | Arial,Helvetica,Times New Roman等常用字体 | 字体族 |
| font-weight | string | 是 | normal,bold | 字体粗细 |
| text-align | string | 是 | left,center,right | 文本对齐方式 |
| color | string | 是 | 十六进制颜色值，如#FF0000 | 文本颜色 |
| text | string | 是 | 任意字符串 | 要显示的文本内容 |

#### 指令备注
- 当指定width且文本超出时会自动换行
- 支持Unicode字符，可显示中文等多语言文本
- 文本内容参数位于最后，便于处理包含逗号的文本内容

#### 示例
```
text,10,5,40,8,12,Arial,bold,center,#000000,产品名称
```

### 2. 条形码指令 (barcode)

#### 指令语法
```
barcode,<条码类型>,<X坐标>,<Y坐标>,<宽度>,<高度>,<是否显示值>,<条码数据>
```

#### 指令描述
用于在标签上生成条形码

#### 指令参数
| 参数名 | 类型 | 必填 | 有效值 | 描述 |
|--------|------|------|--------|------|
| type | string | 是 | CODE128,EAN13,EAN8,CODE39,CODE93等标准条码类型 | 条形码类型 |
| x | number | 是 | 数值 ≥ 0 | 条形码左上角X坐标 |
| y | number | 是 | 数值 ≥ 0 | 条形码左上角Y坐标 |
| width | number | 是 | 数值 > 0 | 条形码宽度 |
| height | number | 是 | 数值 > 0 | 条形码高度 |
| display-value | boolean | 是 | true,false | 是否显示条码值 |
| data | string | 是 | 符合对应条码类型规则的字符串 | 条形码数据 |

#### 指令备注
- 不同条码类型对数据格式有不同要求
- CODE128支持ASCII全部128个字符
- 条码数据参数位于最后，避免数据中包含逗号导致解析错误

#### 示例
```
barcode,CODE128,5,15,50,10,true,1234567890128
```

### 3. 二维码指令 (qrcode)

#### 指令语法
```
qrcode,<X坐标>,<Y坐标>,<尺寸>,<纠错等级>,<二维码数据>
```

#### 指令描述
用于在标签上生成二维码

#### 指令参数
| 参数名 | 类型 | 必填 | 有效值 | 描述 |
|--------|------|------|--------|------|
| x | number | 是 | 数值 ≥ 0 | 二维码左上角X坐标 |
| y | number | 是 | 数值 ≥ 0 | 二维码左上角Y坐标 |
| size | number | 是 | 数值 > 0 | 二维码尺寸 |
| ecc | string | 是 | L,M,Q,H | 纠错等级 |
| data | string | 是 | 任意字符串 | 二维码数据 |

#### 指令备注
- 数据长度影响二维码密度
- 纠错等级越高可纠正的错误越多，但会降低数据容量
- 二维码数据参数位于最后，避免数据中包含逗号导致解析错误

#### 示例
```
qrcode,45,15,20,Q,https://example.com/product/12345
```

### 4. 图片指令 (image)

#### 指令语法
```
image,<X坐标>,<Y坐标>,<宽度>,<高度>,<图片路径>
```

#### 指令描述
用于在标签上插入图片

#### 指令参数
| 参数名 | 类型 | 必填 | 有效值 | 描述 |
|--------|------|------|--------|------|
| x | number | 是 | 数值 ≥ 0 | 图片左上角X坐标 |
| y | number | 是 | 数值 ≥ 0 | 图片左上角Y坐标 |
| width | number | 是 | 数值 > 0 | 图片宽度 |
| height | number | 是 | 数值 > 0 | 图片高度 |
| src | string | 是 | 本地图片路径或Base64编码字符串 | 图片路径或Base64编码 |

#### 指令备注
- 支持JPG、PNG、GIF等常见格式
- 图片路径参数位于最后，便于处理包含逗号的路径

#### 示例
```
image,5,5,15,10,logo.png
```

### 5. 直线指令 (line)

#### 指令语法
```
line,<起点X>,<起点Y>,<终点X>,<终点Y>,<线条粗细>,<颜色>
```

#### 指令描述
用于在标签上绘制直线

#### 指令参数
| 参数名 | 类型 | 必填 | 有效值 | 描述 |
|--------|------|------|--------|------|
| x1 | number | 是 | 数值 ≥ 0 | 起点X坐标 |
| y1 | number | 是 | 数值 ≥ 0 | 起点Y坐标 |
| x2 | number | 是 | 数值 ≥ 0 | 终点X坐标 |
| y2 | number | 是 | 数值 ≥ 0 | 终点Y坐标 |
| stroke | number | 是 | 数值 > 0 | 线条粗细 |
| color | string | 是 | 十六进制颜色值，如#FF0000 | 线条颜色 |

#### 指令备注
- 可用于分隔不同信息区域

#### 示例
```
line,0,30,70,30,0.5,#FF0000
```

### 6. 矩形指令 (rectangle)

#### 指令语法
```
rectangle,<X坐标>,<Y坐标>,<宽度>,<高度>,<边框粗细>,<填充颜色>,<边框颜色>
```

#### 指令描述
用于在标签上绘制矩形

#### 指令参数
| 参数名 | 类型 | 必填 | 有效值 | 描述 |
|--------|------|------|--------|------|
| x | number | 是 | 数值 ≥ 0 | 矩形左上角X坐标 |
| y | number | 是 | 数值 ≥ 0 | 矩形左上角Y坐标 |
| width | number | 是 | 数值 > 0 | 矩形宽度 |
| height | number | 是 | 数值 > 0 | 矩形高度 |
| stroke | number | 是 | 数值 ≥ 0 | 边框粗细 |
| fill | string | 是 | 十六进制颜色值或transparent | 填充颜色 |
| color | string | 是 | 十六进制颜色值，如#FF0000 | 边框颜色 |

#### 指令备注
- 可用于突出显示重要内容或作为背景装饰

#### 示例
```
rectangle,0,0,70,40,0.3,#FFFF00,#000000
```

### 7. 标签整体设置指令 (label)

#### 指令语法
```
label,<宽度>,<高度>,<背景色>,<内边距>
```

#### 指令描述
用于设置整个标签的基本属性

#### 指令参数
| 参数名 | 类型 | 必填 | 有效值 | 描述 |
|--------|------|------|--------|------|
| width | number | 是 | 数值 > 0 | 标签宽度 |
| height | number | 是 | 数值 > 0 | 标签高度 |
| background | string | 是 | 十六进制颜色值，如#FFFFFF | 标签背景色 |
| padding | number | 是 | 数值 ≥ 0 | 标签内边距 |

#### 指令备注
- 一般放在标签内容的最前面
- 决定标签的整体尺寸和背景

#### 示例
```
label,70,40,#F0F0F0,2
```
