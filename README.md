# 商品标签伪指令设计和实现渲染查看

该仓库包含商品标签或外包装标签的伪指令设计与实现方案，用于根据标签打印指令实时渲染标签的显示效果，方便根据客户需求设计符合要求的标签内容和布局。

## 文档列表

- [设计文档](docs/DESIGN.md) - 系统整体设计
- [标签指令定义](docs/LABEL_INSTRUCTIONS.md) - 详细的标签指令规范

## 项目结构

```
src/
├── index.html          # 主页面
├── styles/
│   └── main.css        # 主样式文件
├── models/
│   ├── instruction.js         # 指令类定义
│   ├── label.js               # 标签数据模型
│   ├── instruction-parser.js  # 指令解析器
│   ├── help-data.js           # 帮助信息数据
│   └── utils.js               # 工具函数
├── views/
│   └── label-renderer.js      # 标签渲染器
└── controllers/
    ├── main.js                # 主应用控制器
    ├── label-editor.js        # 标签编辑器控制器
    ├── label-designer.js      # 标签设计器控制器
    └── label-previewer.js     # 标签预览器控制器
```

## 如何运行

1. 使用浏览器直接打开 `src/index.html` 文件即可运行
2. 在左侧文本框中输入标签指令
3. 点击"渲染标签"按钮查看效果

## 功能特点

- 模块化设计，易于扩展和维护
- 支持多种标签元素（文本、条形码、二维码、图片、直线、矩形等）
- 实时预览标签效果
- 响应式设计，适配不同屏幕尺寸
- 可视化标签设计器，支持拖拽调整元素位置
- 支持多元素选择和批量属性修改
- 支持元素对齐方式设置
- 支持标签指令按坐标排序下载
- 完善的指令帮助文档系统
